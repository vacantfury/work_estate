# Deliberation — the hub's council

*The decision function for decision-grade moments (design principle 22), ported from the maintainer's deliberation practice as know-how (principle 2): one question, three differently-grounded reads, one synthesized recommendation, the user decides. The value is the separation of groundings: three seats reading DISJOINT register sets cannot collapse into one voice, so the real tensions of employment work (deliver now vs position long, the team's need vs the user's way and capacity) surface instead of being averaged away silently. Estate-wide law consumed by every project; the runtime function is the hub's.*

## When it convenes — the trigger bar

Decision-grade moments only: a project accept/shape/decline, an initiative pitch, a negotiation stance, review-narrative framing, a presence or pace baseline change, any choice that closes options or commits the user externally. Everyday tasks never convene it: ceremony on small decisions would kill the practice. Any project may convene it; the hub runs it.

## The three seats

Each seat is a GROUNDING, not a persona: it argues only from its own register set and cites lines. A position without citations carries no weight — evidence or silence, the same rule as `career.md`. Three prompts on one vibe is not a council; three register-grounded reads is.

- **First-person seat — works as the user.** Grounding: the self-model (`self-model.md`), the worklog and its candid notes (`work-record.md`), the communication log, the health tracker. Answers: what would the user actually do, in their own style, and what can they actually sustain? Well-being above the hard floors argues here.
- **Positioning seat — the long-term target.** Grounding: the promotion dossier (`career.md`), the company store: reward map, themes, leader trajectories (`company-watch.md`). Answers: which option compounds level, reputation, relationships, and alignment with where the company is actually going?
- **Delivery seat — short-term urgency.** Grounding: the portfolio board and project records (`project-lifecycle.md`), current commitments and deadlines, the manager's stated expectations, the team's ceremonies. Answers: what ships, what was promised, what does the team need now?

## Procedure

1. Frame the question in one sentence, with its do-nothing consequence.
2. Each seat reads its registers and states its position with citations. Separate agent jobs where the runtime allows; three sequential passes in one session otherwise. The seats do not see each other's positions until all three exist.
3. Synthesize: where the seats agree, that is the recommendation; where they conflict, the conflict is stated plainly, never averaged away.
4. Deliver as the standard choice surface (`human-agent-collaboration.md`): the options, ONE recommendation with its why, the do-nothing consequence, the named default.
5. The user decides. Record the decision.

## Hard rules

- **Health floors are law, not a seat** (principle 13): they bind before deliberation, and the delivery seat can never argue past them.
- **Advisory only, no new decision channel:** the council informs decisions the modules already own (the project pipeline's decide step, the report's plan review); it never becomes a parallel authority, and nothing it outputs escapes the prepare-only gates or the autonomy gradient's permanent boundaries (`work-engine.md`).
- **Decision records live with the deciding project:** a project decision on the portfolio board or in the project's record. Estate-wide decisions (a presence baseline, a boundary call, an estate reshape) land in the hub's decision log, `local/state/decisions.md`: one dated entry — question · each seat's position in one line · recommendation · the user's decision · outcome (filled later). The outcome column is the calibration path: the periodic self-audit (`estate-structure.md`) reads decided-vs-outcome so the council's advice quality is tracked, never assumed.
- **Plain functional names:** seats are named by their grounding, never personified.

## Fold-away note (for the unfold's A5 pass)
