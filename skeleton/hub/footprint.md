# Footprint register

*Every personal item on this machine, logged the moment it lands, its exit known at entry. The device-return procedure walks this register at offboarding, reimage, repair, or loss: issuer-side revocation first, local deletion second. A personal item found on the machine with no line is a defect. An empty register is a trivially-clean exit.*
